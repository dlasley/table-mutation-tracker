# Documentation project instructions

This is the Mintlify documentation site for Table Mutation Tracker. Pages are MDX with YAML frontmatter; configuration is in `docs.json`. Run `npx mint validate` and `npx mint broken-links` before committing.

## Content boundaries

- The site is public. Student data is not. Never use real snapshot content, class names, teacher names, school names, or email domains. Use invented values and `example.com` / `example.edu` hosts.
- Do not publish the real scraper host, AWS account ID, or data repository contents. Use placeholders such as `<scraper-host>` and `<account>`.
- Call the portal "SIS" or "student information system", never a vendor's product name.
- `openapi.json` is generated by `scripts/export_openapi.py`. Do not edit it by hand.
