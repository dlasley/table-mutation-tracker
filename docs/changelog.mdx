<Update label="2026-11-15" description="Frontend requires basic auth and surfaces read failures" tags={["Frontend"]}>
  ## Basic auth is required

  The frontend no longer serves without credentials. If `BASIC_AUTH_CREDENTIALS` is missing or malformed, every request returns 503, except on Vercel preview deployments and `next dev`. Set it before you deploy this version. See [The frontend returns 503 Service unavailable](/operations/troubleshooting).

  ## No false deletions on read errors

  When the frontend cannot read a snapshot from the data repo for any reason other than a missing file, the day view shows an error instead of comparing against an empty snapshot. Previously a GitHub outage or an expired token could make the day view report changes that never happened.

  ## Voice agent tokens

  The token endpoint now sets the room name, agent, and participant name itself and ignores those fields from the browser. The browser sends only a device ID and the selected persona.
</Update>

<Update label="2026-11-14" description="Consistent change detection and safer error responses" tags={["Diffing", "API", "Pipeline", "Docs"]}>
  ## Error IDs instead of tracebacks

  Error responses from the scraper no longer include a stack trace. They return the exception message, with URLs replaced by `<url>`, and an `error_id`. The scraper logs the full trace under the same ID, and the scrape failure email shows it. Re-import the n8n workflow so the email picks up the new field. See [Find the stack trace for an error](/operations/troubleshooting#find-the-stack-trace-for-an-error).

  `/append-index` now rejects a `date` that is not `YYYY-MM-DD` or a `time` that is not six digits with 422. The scraper checks the webhook secret before it parses the request body, so a bad secret returns 401 even when the body is malformed.

  ## n8n settings moved to environment variables

  The n8n workflow reads the scraper URL, data repository, and alert email address from the `SCRAPER_BASE_URL`, `DATA_REPO`, and `ALERT_EMAIL` environment variables on the n8n host. Set them before importing the updated workflow. See [Environment variables](/guides/n8n-workflow#environment-variables).

  ## Flags and comments diffed the same way everywhere

  The calendar counts and the day view now compare the same fields. Status flags such as late and missing appear as individual rows in the day view, and comment changes count toward the calendar. A test fails if the two implementations drift apart again.

  ## Documentation site

  These docs, including an API reference generated from the scraper's OpenAPI spec.
</Update>

<Update label="2026-05-15" description="Incremental index updates" tags={["Pipeline", "API"]}>
  ## /append-index

  Each scrape now adds one entry to the rolling index instead of recomputing all of it. A full rebuild had grown past the container platform's 120-second request limit. When a snapshot arrives out of order, the endpoint returns 409 and n8n falls back to a full rebuild.

  ## Credential handling in n8n

  The webhook secret moved into a shared n8n credential, so it no longer appears in the exported workflow.
</Update>

<Update label="2026-04-15" description="GPA" tags={["Frontend"]}>
